Calm Calendar

一款免费、无广告的 Windows 桌面日历，以日、周、月和日程视图显示你的 Google 日历，带桌面小组件，可在任何应用中快速添加活动。

从 Microsoft Store 获取 即将上线 从 GitHub 下载

功能

在原生 Windows 窗口中使用 Google 日历，没有广告。

  • 日、周、月和日程

    在快速的原生窗口中使用 Google 日历。拖动活动即可移动或调整时长；支持重复、邀请对象和时区。

  • 桌面小组件

    时钟、距下一个活动的倒计时、迷你月历和即将到来的活动，直接显示在桌面上。

  • 在任何应用中快速添加

    在任何地方按 Ctrl+Alt+空格，输入“明天下午3点 英语课 50分钟”，再按 Enter。能理解应用支持的全部 13 种语言。

  • 一键加入通话

    为 Google Meet、Zoom 和 Teams 提供“加入”按钮；会议开始时还可在所有窗口之上显示醒目提醒。

  • 多个账号

    工作和个人 Google 账号显示在同一窗口中，账号之间的时间冲突会被标出。还可以通过 .ics 链接添加课程表或 Outlook 日历。

  • 键盘操作同样快捷

    Ctrl+K 执行任意命令，方向键在活动之间切换，E 编辑，Ctrl+D 复制。按 ? 查看完整列表。

  • 五种风格，浅色与深色

    经典、纸张、黑曜石、橱窗或黑白，并可选择字体。小组件会跟随所选风格。

  • 提醒

    Google 日历的提醒以 Windows 通知的形式显示。

  • 离线可用

    没有网络时显示最近一次加载的日程。

  • 隐私

    应用没有自己的服务器，没有广告，也不做跟踪。你的数据只在你的电脑和 Google 之间传输。

Calm Calendar 如何使用你的 Google 数据

Calm Calendar 使用你的 Google 账号登录，并请求两项日历权限：

  • 查看你的日历列表 用于显示日历的名称和颜色，并让你隐藏或显示每个日历。
  • 查看和编辑你日历中的活动 用于显示你的活动；当你在应用中操作时创建、编辑、移动和删除活动；以及显示提醒通知。

登录时还会共享你的 Google 账号电子邮件地址，以便应用显示你登录的是哪个账号。

一切都在你的电脑上运行。应用直接与 Google 通信；我们从不接收、存储或分享你的数据。你可以随时退出登录或撤销访问权限。

常见问题

免费吗？

是的。Calm Calendar 免费且没有广告。

支持哪些 Windows 版本？

Windows 10 1809 及更高版本，以及 Windows 11。

能用于 Outlook 吗？

部分可以。Calm Calendar 是为 Google 日历设计的，但你可以在“设置 → 日历订阅”中通过 .ics 链接添加 Outlook 日历或其他任何日历。这类日历为只读。

支持哪些语言？

英语、西班牙语、葡萄牙语、法语、德语、俄语、乌克兰语、白俄罗斯语、中文、日语、印地语、孟加拉语和阿拉伯语。应用默认跟随 Windows 语言，也可以在“设置 → 语言”中选择。

可以使用多个 Google 账号吗？

可以。按需添加任意数量的账号；它们的日历会一起显示，与其他账号活动时间冲突的会议会被标出。

如何删除我的数据？

在应用中退出登录：这会撤销访问权限，并删除保存在你电脑上的数据。你也可以随时在以下页面撤销访问权限： myaccount.google.com/permissions。

Calm Calendar 是一款 Windows 桌面日历应用，与你的 Google 日历配合使用，由 Arseni（“我们”）开发。本政策说明应用会访问哪些数据、如何使用和存储这些数据，以及你如何删除它们。

简而言之：Calm Calendar 没有自己的服务器。你的日历数据只在你的电脑和 Google 之间传输。我们不收集、不接收、不出售也不分享你的数据，应用中没有广告、分析或跟踪。

应用访问的数据

使用 Google 登录时，你会被要求授予 Calm Calendar 以下权限。应用仅将每项权限用于所述功能。

Calm Calendar 请求的 Google 权限及各自用途
Google 权限 应用如何使用
calendar.calendarlist.readonly查看你的日历列表 在侧栏中显示你的日历及其名称和颜色，让你显示或隐藏每个日历，并读取每个日历的默认提醒时间用于通知。
calendar.events查看和编辑你日历中的活动 在日历视图和桌面小组件中显示你的活动；当你在应用中操作时创建、编辑、移动和删除活动，包括你邀请的对象（随后 Google 会通过电子邮件向他们发送邀请）以及你设置的路程时间（保存在活动的私有字段中）；在你使用搜索时搜索你的活动；读取活动提醒以显示 Windows 通知；读取你在设置中选择的国家/地区的 Google 公共节假日日历。
openid、email你的 Google 账号电子邮件地址 显示你登录的是哪个账号。

应用不会访问你的 Gmail、联系人、Google 云端硬盘或任何其他 Google 数据，除非你自己创建、编辑、移动或删除活动，否则不会更改你的日历。

数据的使用方式

Google 用户数据仅用于提供你在应用中看到的日历功能。这些数据不用于广告，不会被出售，也不会用于开发、改进或训练人工智能或机器学习模型。Calm Calendar 的任何人都不会查看你的数据。

数据的存储位置

所有处理都在你的电脑上进行。Calm Calendar 通过加密的 HTTPS 连接直接与 Google 的服务器（accounts.google.com、oauth2.googleapis.com、www.googleapis.com）通信。不会向我们或任何其他第三方发送任何内容。

如果你通过链接添加日历订阅（设置 → 日历订阅），应用还会直接从你输入的地址下载该 .ics 文件；该网站会看到一个来自你电脑的普通下载请求。点击活动的地点会在浏览器中打开 Google 地图并搜索该地点。

应用会在你的电脑上保存以下内容：

  • 登录令牌。Google 刷新令牌存储在 Windows 凭据管理器中，受你的 Windows 账户保护。短期访问令牌仅在应用运行期间保存在内存中。
  • 账号电子邮件地址，用于显示已登录的账号。
  • 最近加载的日历数据。从 Google 收到的最新日历列表和活动保存在应用的本地存储中，以便在离线时日历和小组件仍能显示你的日程。最多保留最近 80 次响应，更早的会被自动删除。
  • 日历订阅。你添加的链接以及每个日历最近一次下载的副本，用于离线显示。删除订阅时会同时删除其副本。
  • 设置，例如主题、语言、小组件位置以及显示哪些日历。
  • 日志文件。位于 %LOCALAPPDATA%\com.arseni.calmcalendar\logs 的技术日志会记录应用启动、登录、退出登录和错误，以便排查问题。其中不包含活动标题或说明，也不包含令牌；电子邮件地址会缩写为首字母加域名（a***@gmail.com）。最多保留五个 1 MB 的文件，更早的会被自动删除。日志不会自行离开你的电脑：只有当你把它附在发给支持的电子邮件中时（设置 → “打开日志文件夹”），我们才会看到。

我们如何保护你的数据

你的日历数据是敏感信息，因此 Calm Calendar 的设计是让数据留在你的电脑上，并限制谁和什么能够接触到它们。目前采用的保护机制如下：

  • 传输加密。与 Google 的所有通信均使用 HTTPS（TLS）。应用没有其他网络目的地，中间也没有我们的服务器。
  • 安全登录。你在常用浏览器中、在 Google 自己的页面上登录，因此应用永远看不到你的 Google 密码。登录使用面向桌面应用的 OAuth 2.0 授权码流程，配合 PKCE（RFC 7636）和随机 state 校验，并且只在一个临时本地地址（127.0.0.1）上接收响应，登录结束后该地址即关闭。
  • 受保护的登录令牌。长期刷新令牌只存储在 Windows 凭据管理器中，它使用与你的 Windows 账户绑定的密钥（Windows Data Protection API）对其加密。该令牌从不写入明文文件、日志或设置。短期访问令牌只保存在内存中。
  • 最小权限。应用只请求上面列出的 Google 权限，不请求 Gmail、云端硬盘或联系人的任何权限。
  • 受限的应用窗口。应用界面在严格的内容安全策略（Content Security Policy）下运行：它只能加载自身的文件，不能发起网络请求，也不能加载远程代码。只有应用的原生部分与 Google 通信，而且只与上述三个 Google 主机通信。
  • 本地缓存。最近加载的日历数据保存在你 Windows 用户配置文件内的应用私有存储中，因此同一台电脑上的其他 Windows 用户默认无法读取。应用不会为该缓存额外加密；为了防范能实际接触你电脑的人，我们建议开启 Windows 设备加密（BitLocker）。退出登录时缓存会被删除。
  • 我们无法访问。我们不运行服务器，也不接收数据，因此我们这边不存在可能被访问或泄露的用户数据库，Calm Calendar 的任何人都无法读取你的日历。
  • 干净的日志。日志中不含活动内容和令牌，电子邮件地址也经过遮蔽。
  • 撤销访问。退出登录会撤销应用在 Google 的访问权限并从你的电脑中删除令牌；你也可以随时在 Google 账号中撤销访问权限。
  • 更新。安全修复会以应用更新的形式发布（通过 Microsoft Store 或 GitHub 发布）。如需报告漏洞，请发送邮件至 support@calmcalendar.co.uk。

删除你的数据

  • 在应用中退出登录（侧栏中账号旁边的按钮）。这会撤销应用在 Google 的访问权限，从 Windows 凭据管理器中删除登录令牌，并从你的电脑中删除已保存的电子邮件地址和日历数据。你的日历本身仍保留在 Google 账号中。
  • 随时在 Google 账号中撤销访问权限：myaccount.google.com/permissions。
  • 卸载应用以删除其设置。如果你是从 Microsoft Store 安装的，Windows 会一并删除应用的本地数据。对于其他安装方式，你还可以删除 %APPDATA%\com.arseni.calmcalendar 和 %LOCALAPPDATA%\com.arseni.calmcalendar 文件夹（后者存放日志）。

共享与披露

我们不会向任何人共享、出售、出租或转让你的数据。由于我们从未接收你的数据，因此也无法披露这些数据。

Calm Calendar 对从 Google API 获得的信息的使用及向任何其他应用的传输，将遵守 Google API Services User Data Policy，包括其中的有限使用（Limited Use）要求。

Microsoft Store 与 Google

如果你从 Microsoft Store 安装应用，下载、更新和任何购买均由 Microsoft 依据 Microsoft 隐私声明处理。你的 Google 账号和日历受 Google 隐私权政策约束。

儿童

Calm Calendar 并非面向 13 岁以下儿童，我们不会在知情的情况下收集儿童的个人信息。

本政策的变更

如果本政策发生变更，新版本将以新的生效日期发布在此地址。重大变更也会在应用的版本说明中提及。

联系方式

关于本政策或你的数据的问题：support@calmcalendar.co.uk。

# Политика конфиденциальности Calm Calendar

Действует с 11 ноября 2026 года

Calm Calendar — календарь для Windows, который работает с вашим Google Календарём. Разработчик — Arseni («мы»). Здесь описано, к каким данным приложение получает доступ, как их использует и хранит и как их удалить.

Коротко: у Calm Calendar нет своих серверов. Данные календаря передаются только между вашим компьютером и Google. Мы не собираем, не получаем, не продаём и не передаём ваши данные. В приложении нет рекламы, аналитики и слежки.

## К каким данным приложение получает доступ

При входе через Google вас попросят выдать Calm Calendar разрешения ниже. Каждое используется только для указанной функции.

| Разрешение Google | Что с ним делает приложение |
|---|---|
| `calendar.calendarlist.readonly` — просмотр списка календарей | Показывает ваши календари на боковой панели с названиями и цветами, позволяет скрывать и показывать каждый, читает время напоминаний по умолчанию для уведомлений. |
| `calendar.events` — просмотр и изменение событий | Показывает события в видах календаря и в виджете; создаёт, изменяет, переносит и удаляет события, когда вы делаете это в приложении, в том числе с гостями, которых вы приглашаете (Google присылает им приглашение по почте), и временем в пути, которое сохраняется в скрытых полях события; ищет события, когда вы пользуетесь поиском; читает напоминания событий, чтобы показывать уведомления Windows; читает публичный календарь праздников Google той страны, которую вы выбрали в настройках. |
| `openid`, `email` — адрес почты аккаунта Google | Показывает, под каким аккаунтом выполнен вход. |

Приложение не получает доступ к Gmail, контактам, Google Диску и другим данным Google и не меняет календари, пока вы сами не создадите, не измените, не перенесёте или не удалите событие.

## Как используются данные

Данные из Google используются только для функций календаря, которые вы видите в приложении. Они не используются для рекламы, не продаются и не используются для создания, улучшения или обучения моделей искусственного интеллекта и машинного обучения. Никто из Calm Calendar ваши данные не просматривает.

## Где хранятся данные

Вся обработка происходит на вашем компьютере. Calm Calendar обращается напрямую к серверам Google (`accounts.google.com`, `oauth2.googleapis.com`, `www.googleapis.com`) по защищённому соединению HTTPS. Ни нам, ни кому-либо ещё ничего не передаётся.

Если вы добавили подписку на календарь по ссылке (Настройки → Подписки на календари), приложение ещё скачивает этот файл .ics прямо с указанного адреса; сайт видит обычный запрос на скачивание с вашего компьютера. Щелчок по месту встречи открывает Google Карты в браузере с поиском этого места.

На вашем компьютере приложение хранит:

- **Токен входа.** Токен обновления Google хранится в диспетчере учётных данных Windows и защищён вашей учётной записью Windows. Короткоживущий токен доступа хранится только в памяти, пока приложение запущено.
- **Адреса почты аккаунтов** — чтобы показывать, под какими аккаунтами выполнен вход.
- **Недавно загруженные данные календаря.** Последние полученные от Google списки календарей и события сохраняются в локальном хранилище приложения, чтобы календарь и виджет показывали расписание без сети. Хранятся не больше 80 последних ответов, более старые удаляются автоматически.
- **Подписки на календари**: добавленные ссылки и последняя скачанная копия каждого календаря, чтобы показывать его без сети. При удалении подписки её копия удаляется.
- **Настройки**: тема, язык, положение виджета, какие календари показаны.
- **Журнал работы.** Технический журнал в `%LOCALAPPDATA%\com.arseni.calmcalendar\logs` записывает запуски приложения, входы и выходы и ошибки, чтобы можно было разобраться в сбое. В нём нет названий и описаний событий и токенов; адреса почты сокращены до первой буквы и домена (`a***@gmail.com`). Хранится до пяти файлов по 1 МБ, более старые удаляются автоматически. Сам по себе журнал никуда не отправляется: мы увидим его, только если вы приложите его к письму в поддержку (Настройки → «Открыть папку журнала»).

## Как мы защищаем ваши данные

Данные календаря чувствительны, поэтому Calm Calendar устроен так, чтобы они оставались на вашем компьютере, а доступ к ним был ограничен. Применяются такие меры защиты:

- **Шифрование при передаче.** Весь обмен с Google идёт по HTTPS (TLS). Других сетевых адресов у приложения нет, наших серверов-посредников тоже нет.
- **Безопасный вход.** Вход выполняется в обычном браузере на странице самого Google, поэтому приложение не видит ваш пароль от Google. Используется схема OAuth 2.0 с кодом авторизации для настольных приложений, PKCE (RFC 7636) и проверка случайного параметра `state`; ответ принимается только на временном локальном адресе (`127.0.0.1`), который закрывается после входа.
- **Защита токена входа.** Долгоживущий токен обновления хранится только в диспетчере учётных данных Windows, который шифрует его ключами, привязанными к вашей учётной записи Windows (Windows Data Protection API). В обычный файл, журнал или настройки он не записывается. Короткоживущий токен доступа хранится только в памяти.
- **Минимум прав.** Приложение запрашивает только перечисленные выше разрешения Google, ничего для Gmail, Диска или контактов.
- **Ограниченное окно приложения.** Интерфейс работает под строгой политикой безопасности содержимого (Content Security Policy): он загружает только собственные файлы и не может выполнять сетевые запросы и подгружать чужой код. С Google общается только встроенная нативная часть приложения и только с тремя хостами Google, указанными выше.
- **Локальный кэш.** Недавно загруженные данные календаря лежат в закрытом хранилище приложения в профиле вашего пользователя Windows, поэтому другие пользователи этого компьютера по умолчанию их не прочитают. Собственного шифрования кэша приложение не добавляет; для защиты от человека с физическим доступом к компьютеру рекомендуем включить шифрование устройства Windows (BitLocker). При выходе из аккаунта кэш удаляется.
- **У нас нет доступа.** У нас нет серверов, и данные к нам не попадают, поэтому на нашей стороне нет базы данных пользователей, к которой можно получить доступ или из которой возможна утечка; прочитать ваш календарь никто из Calm Calendar не может.
- **Чистота журнала.** В журнале нет содержимого событий и токенов, адреса почты в нём скрыты.
- **Отзыв доступа.** При выходе приложение отзывает свой доступ в Google и удаляет токен с компьютера; доступ можно в любой момент отозвать и в аккаунте Google.
- **Обновления.** Исправления безопасности выходят обновлениями приложения (через Microsoft Store или релизы на GitHub). О найденной уязвимости пишите на [support@calmcalendar.co.uk](mailto:support@calmcalendar.co.uk).

## Как удалить данные

- **Выйдите** из аккаунта в приложении (кнопка рядом с аккаунтом на боковой панели). Приложение отзовёт свой доступ в Google, удалит токен из диспетчера учётных данных Windows, сохранённый адрес почты и сохранённые данные календаря. Сами календари остаются в вашем аккаунте Google.
- **Отзовите доступ** в любой момент в аккаунте Google: [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
- **Удалите приложение**, чтобы стереть настройки. При установке из Microsoft Store Windows удаляет локальные данные приложения вместе с ним. При другой установке можно удалить папки `%APPDATA%\com.arseni.calmcalendar` и `%LOCALAPPDATA%\com.arseni.calmcalendar` (во второй лежит журнал).

Использование и передача приложением Calm Calendar информации, полученной через API Google, в любые другие приложения соответствуют [Правилам использования данных пользователей сервисов Google API](https://developers.google.com/terms/api-services-user-data-policy), включая требования ограниченного использования (Limited Use).

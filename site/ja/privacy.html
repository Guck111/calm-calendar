Calm Calendar は、Google カレンダーと連携する Windows 用のデスクトップ カレンダー アプリで、Arseni（以下「当方」）が開発しています。本ポリシーでは、アプリがどのデータにアクセスし、それをどのように使用・保存するか、またどのように削除できるかを説明します。

要点：Calm Calendar は独自のサーバーを持ちません。カレンダーのデータはお使いのコンピューターと Google の間でのみやり取りされます。当方がデータを収集、受信、販売、共有することはなく、アプリには広告、アクセス解析、トラッキングは一切含まれていません。

アプリがアクセスするデータ

Google でログインすると、Calm Calendar に以下の権限を許可するよう求められます。アプリは各権限を記載の機能にのみ使用します。

Calm Calendar が求める Google の権限と、それぞれの用途
Google の権限 アプリでの用途
calendar.calendarlist.readonlyカレンダーの一覧の表示 サイドバーにカレンダーを名前と色付きで表示し、それぞれの表示・非表示を切り替えられるようにします。また、通知のために各カレンダーのデフォルトのリマインダー時間を読み取ります。
calendar.eventsカレンダーの予定の表示と編集 カレンダーの各表示とデスクトップ ウィジェットに予定を表示します。アプリで操作したときに予定を作成・編集・移動・削除します（招待したゲストを含みます。その場合、Google がゲストに招待メールを送信します。また、設定した移動時間は予定の非公開フィールドに保存されます）。検索を使ったときに予定を検索します。Windows の通知を表示するために予定のリマインダーを読み取ります。設定で選んだ国の Google の公開祝日カレンダーを読み取ります。
openid、emailGoogle アカウントのメールアドレス どのアカウントでログインしているかを表示します。

アプリは Gmail、連絡先、Google ドライブ、その他の Google データにはアクセスしません。また、お客様自身が予定を作成・編集・移動・削除しない限り、カレンダーを変更することはありません。

データの使い方

Google ユーザーデータは、アプリに表示されるカレンダー機能の提供にのみ使用されます。広告には使用されず、販売されることもなく、人工知能や機械学習モデルの開発・改善・学習に使用されることもありません。Calm Calendar の誰もお客様のデータを閲覧しません。

データの保存場所

すべての処理はお使いのコンピューター上で行われます。Calm Calendar は暗号化された HTTPS 接続で Google のサーバー（accounts.google.com、oauth2.googleapis.com、www.googleapis.com）と直接通信します。当方やその他の第三者に何かが送信されることはありません。

リンクでカレンダーの購読を追加した場合（設定 → カレンダーの購読）、アプリは入力されたアドレスからその .ics ファイルを直接ダウンロードします。そのサイトには、お使いのコンピューターからの通常のダウンロード要求として見えます。予定の場所をクリックすると、その場所を検索した状態でブラウザーに Google マップが開きます。

アプリはお使いのコンピューターに次のものを保存します。

  • ログイン トークン。Google のリフレッシュ トークンは Windows 資格情報マネージャーに保存され、お使いの Windows アカウントによって保護されます。有効期間の短いアクセス トークンは、アプリの実行中にメモリ上にのみ保持されます。
  • アカウントのメールアドレス。どのアカウントでログインしているかを表示するためです。
  • 最近読み込んだカレンダー データ。Google から受け取った最新のカレンダー一覧と予定はアプリのローカル ストレージに保存され、オフラインでもカレンダーとウィジェットに予定が表示されるようにします。保存されるのは最新の 80 件の応答までで、古いものは自動的に削除されます。
  • カレンダーの購読。追加したリンクと、各カレンダーの最後にダウンロードしたコピーです。オフラインで表示するためのもので、購読を削除するとそのコピーも削除されます。
  • 設定。テーマ、言語、ウィジェットの位置、表示するカレンダーなどです。
  • ログ ファイル。%LOCALAPPDATA%\com.arseni.calmcalendar\logs にある技術ログには、問題を調査できるよう、アプリの起動、ログイン、ログアウト、エラーが記録されます。予定のタイトルや説明、トークンは含まれず、メールアドレスは先頭の 1 文字とドメインに短縮されます（a***@gmail.com）。1 MB のファイルが最大 5 つまで保存され、古いものは自動的に削除されます。ログが勝手にコンピューターの外に送られることはありません。お客様がサポートへのメールに添付した場合（設定 → 「ログフォルダーを開く」）にのみ、当方が目にします。

データの保護方法

カレンダーのデータは機密性が高いため、Calm Calendar はデータをお使いのコンピューターにとどめ、誰が・何がアクセスできるかを制限するよう設計されています。以下の保護の仕組みを備えています。

  • 通信の暗号化。Google との通信はすべて HTTPS（TLS）を使用します。アプリにはそれ以外のネットワーク接続先はなく、間に当方のサーバーもありません。
  • 安全なログイン。ログインは普段お使いのブラウザーで、Google 自身のページで行うため、アプリが Google のパスワードを目にすることはありません。ログインにはデスクトップ アプリ向けの OAuth 2.0 認可コード フローを PKCE（RFC 7636）とランダムな state の検証付きで使用し、応答はログイン終了時に閉じられる一時的なローカル アドレス（127.0.0.1）でのみ受け取ります。
  • 保護されたログイン トークン。有効期間の長いリフレッシュ トークンは Windows 資格情報マネージャーにのみ保存され、お使いの Windows アカウントに結び付いた鍵（Windows Data Protection API）で暗号化されます。暗号化されていないファイル、ログ、設定に書き込まれることはありません。有効期間の短いアクセス トークンはメモリ上にのみ保持されます。
  • 最小限の権限。アプリが求めるのは上記の Google の権限のみで、Gmail、ドライブ、連絡先の権限は一切求めません。
  • 制限されたアプリ ウィンドウ。アプリの画面は厳格なコンテンツ セキュリティ ポリシー（Content Security Policy）の下で動作し、自身のファイルしか読み込めず、ネットワーク要求やリモート コードの読み込みはできません。Google と通信するのはアプリのネイティブ部分のみで、相手は上記の 3 つの Google ホストに限られます。
  • ローカル キャッシュ。最近読み込んだカレンダー データは、Windows のユーザー プロファイル内にあるアプリ専用のストレージに保存されるため、同じコンピューターの他の Windows ユーザーは既定では読み取れません。アプリはこのキャッシュに独自の暗号化を追加しません。コンピューターに物理的にアクセスできる人からデータを守るには、Windows のデバイスの暗号化（BitLocker）を有効にすることをおすすめします。キャッシュはログアウト時に削除されます。
  • 当方はアクセスしません。当方はサーバーを運用せず、データも受け取らないため、当方側にはアクセスされたり漏えいしたりしうるユーザーデータのデータベースが存在せず、Calm Calendar の誰もお客様のカレンダーを閲覧できません。
  • ログの配慮。ログには予定の内容やトークンは含まれず、メールアドレスはマスクされています。
  • アクセスの取り消し。ログアウトすると、Google でのアプリのアクセスが取り消され、トークンがコンピューターから削除されます。Google アカウントからいつでもアクセスを取り消すこともできます。
  • アップデート。セキュリティ修正はアプリのアップデートとして提供されます（Microsoft Store または GitHub のリリース経由）。脆弱性の報告は support@calmcalendar.co.uk までお送りください。

データの削除

  • アプリでログアウトします（サイドバーのアカウントの横にあるボタン）。これにより、Google でのアプリのアクセスが取り消され、Windows 資格情報マネージャーからログイン トークンが削除され、保存されたメールアドレスとカレンダー データがコンピューターから削除されます。カレンダー自体は Google アカウントに残ります。
  • Google アカウントからいつでもアクセスを取り消せます：myaccount.google.com/permissions。
  • アプリをアンインストールすると設定が削除されます。Microsoft Store からインストールした場合、Windows がアプリのローカル データも一緒に削除します。その他の方法でインストールした場合は、%APPDATA%\com.arseni.calmcalendar と %LOCALAPPDATA%\com.arseni.calmcalendar（後者にログがあります）のフォルダーも削除できます。

共有と開示

当方はお客様のデータを誰とも共有、販売、貸与、譲渡しません。当方がデータを受け取ることはないため、開示することもできません。

Calm Calendar による Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（制限付き使用（Limited Use）の要件を含む）に準拠します。

Microsoft Store と Google

Microsoft Store からアプリをインストールした場合、ダウンロード、アップデート、購入は Microsoft プライバシー ステートメントに基づいて Microsoft が処理します。Google アカウントとカレンダーには Google プライバシー ポリシーが適用されます。

お子様について

Calm Calendar は 13 歳未満のお子様を対象としておらず、当方がお子様の個人情報を故意に収集することはありません。

本ポリシーの変更

本ポリシーが変更された場合、新しい版を新しい発効日とともにこのアドレスで公開します。重要な変更は、アプリのリリース ノートでもお知らせします。

お問い合わせ

本ポリシーやお客様のデータに関するご質問：support@calmcalendar.co.uk

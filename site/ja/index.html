Calm Calendar

Google カレンダーを日・週・月・スケジュールで表示する、無料で広告なしの Windows 用デスクトップ カレンダー。デスクトップ ウィジェットと、どのアプリからでも使えるクイック追加付き。

Microsoft Store から入手 近日公開 GitHub からダウンロード

主な機能

Google カレンダーをネイティブな Windows ウィンドウで使えます。広告はありません。

  • 日・週・月・スケジュール

    Google カレンダーを高速なネイティブ ウィンドウで。予定をドラッグして移動や長さの変更ができ、繰り返し、ゲスト、タイムゾーンにも対応。

  • デスクトップ ウィジェット

    時計、次の予定までのカウントダウン、ミニ月カレンダー、これからの予定をデスクトップに直接表示。

  • どのアプリからでもクイック追加

    どこでも Ctrl+Alt+Space を押して「明日19時 英会話 50分」と入力し、Enter を押すだけ。アプリの 13 言語すべてを理解します。

  • ワンクリックで通話に参加

    Google Meet・Zoom・Teams 用の「参加」ボタン。会議の開始時に全ウィンドウの最前面に表示する通知も選べます。

  • 複数アカウント

    仕事用と個人用の Google アカウントを 1 つのウィンドウに表示し、アカウント間の重複を表示。時間割や Outlook のカレンダーも .ics リンクで追加できます。

  • キーボードでもすばやく

    Ctrl+K で任意のコマンド、矢印キーで予定間を移動、E で編集、Ctrl+D で複製。? を押すと一覧を表示します。

  • 5 つのスタイル、ライトとダーク

    クラシック、ペーパー、オブシディアン、ショーケース、モノクロから選べ、フォントも選択可能。ウィジェットもスタイルに合わせて変わります。

  • リマインダー

    Google カレンダーのリマインダーを Windows の通知として表示。

  • オフラインでも使える

    接続がないときは、最後に読み込んだスケジュールを表示します。

  • プライバシー

    アプリは独自のサーバーを持たず、広告もトラッキングもありません。データは PC と Google の間でのみやり取りされます。

Calm Calendar による Google データの使い方

Calm Calendar は Google アカウントでログインし、カレンダーに関する 2 つの権限を求めます。

  • カレンダーの一覧の表示 カレンダーを名前と色付きで表示し、それぞれの表示・非表示を切り替えるため。
  • カレンダーの予定の表示と編集 予定を表示し、アプリで操作したときに予定を作成・編集・移動・削除するため、またリマインダー通知を表示するため。

ログイン時には Google アカウントのメールアドレスも共有され、どのアカウントでログインしているかをアプリに表示します。

すべてはお使いのコンピューター上で動作します。アプリは Google と直接通信し、私たちがデータを受け取ったり、保存したり、共有したりすることは一切ありません。いつでもログアウトやアクセスの取り消しができます。

よくある質問

無料ですか？

はい。Calm Calendar は無料で、広告もありません。

対応している Windows のバージョンは？

Windows 10 バージョン 1809 以降と Windows 11 です。

Outlook でも使えますか？

一部対応しています。Calm Calendar は Google カレンダー向けですが、Outlook などのカレンダーを「設定 → カレンダーの購読」で .ics リンクから追加できます。こうしたカレンダーは読み取り専用です。

どの言語に対応していますか？

英語、スペイン語、ポルトガル語、フランス語、ドイツ語、ロシア語、ウクライナ語、ベラルーシ語、中国語、日本語、ヒンディー語、ベンガル語、アラビア語です。アプリは Windows の言語に従いますが、「設定 → 言語」で選ぶこともできます。

複数の Google アカウントを使えますか？

はい。必要なだけアカウントを追加できます。カレンダーはまとめて表示され、別のアカウントの予定と重なる会議には印が付きます。

データを削除するには？

アプリでログアウトしてください。アクセスが取り消され、コンピューターに保存されたデータが削除されます。アクセスはいつでも次のページから取り消すこともできます： myaccount.google.com/permissions。

本規約は、Windows 用デスクトップ アプリ Calm Calendar およびこのウェブサイトに適用されます。Calm Calendar は Arseni（以下「当方」）が開発しています。アプリをインストールまたは使用することで、お客様は本規約に同意したものとみなされます。同意いただけない場合は、アプリを使用しないでください。

アプリについて

Calm Calendar はカレンダー クライアントで、お客様ご自身の Google カレンダーの予定を表示・編集します。アプリは無料で提供されます。機能は変更されることがあり、アプリはいつでも更新または提供終了されることがあります。

Google アカウント

アプリを使用するには、Google アカウントでログインし、カレンダーへのアクセスを許可します。お客様は、ご自身のアカウントと、アプリを通じてカレンダーに加えた変更（予定の作成、編集、移動、削除など）について責任を負います。Google サービスのご利用には、引き続き Google 利用規約が適用されます。アプリのアクセスは myaccount.google.com/permissions でいつでも取り消せます。

アプリがお客様のデータをどのように扱うかは、プライバシー ポリシーに記載しています。

禁止事項

法律や他者の権利を侵害する目的、Google のサービスを妨害する目的、またはアクセス権のないカレンダーにアクセスする目的でアプリを使用しないでください。Google API の制限を回避したり、アプリの Google OAuth 認証情報を不正に使用したりしないでください。

無保証

アプリは「現状のまま」かつ「提供可能な範囲で」提供され、特定目的への適合性や権利非侵害を含め、明示・黙示を問わずいかなる保証もありません。当方は、アプリに誤りがないこと、常に利用できること、リマインダーや通知が常に時間どおりに届くことを保証しません。重要な事柄について、アプリを唯一のリマインダーとして頼らないでください。

責任の制限

法律で認められる最大限の範囲で、当方は、アプリの使用または使用不能から生じる間接的、付随的、特別、結果的損害、またはデータの損失、予定や約束を逃したことについて、一切責任を負いません。本規約のいかなる内容も、お客様に適用される法律の下で制限できない責任を制限するものではありません。

Microsoft Store

Microsoft Store からアプリをインストールした場合、ダウンロードとアップデートには Microsoft Store の規約も適用されます。Microsoft はアプリおよびそのサポートについて責任を負いません。

変更

当方は本規約を更新することがあります。新しい版は、新しい発効日とともにこのアドレスで公開します。変更後もアプリを使い続けた場合、更新後の規約に同意したものとみなされます。

お問い合わせ
